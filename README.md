# Canto e Arte — Pet Shop

Aplicativo Android nativo para uso local em um único celular.

- Cadastro de clientes e pets
- Agenda de banho e tosa
- Produtos e estoque
- Serviços e preços editáveis
- Vendas e caixa
- Dados armazenados localmente no aparelho
- Backup local para exportação

## Compilar

Abra o projeto no Android Studio e execute a tarefa `:app:assembleDebug`. O GitHub Actions também compila o APK em cada envio para a branch `main`.

**Atenção:** faça backups regulares. Os dados locais podem ser perdidos se o aplicativo for desinstalado ou se os dados do app forem apagados.
